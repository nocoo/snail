## 运行

```sh
bun install --frozen-lockfile
bun run dev
```

Vite 只监听 127.0.0.1，端口占用时明确退出，避免自动挪到其他项目端口。`/api/*` 由进程内 Miniflare 运行仓库真实 Worker，前端保留 HMR；修改 Worker 后重启开发进程。无需额外固定 Worker 端口。

开发数据保存在 ignored `.wrangler/dev`，重启不丢失；迁移名记录在本地 `local_migrations`，每份 SQL 与迁移记录在同一 D1 batch 执行。自动化测试使用独立临时存储，不读取开发库。预览构建执行 `bun run build && node scripts/test-server.ts`。

本地使用每次启动生成的测试签名密钥和 `test-local@example.test` 身份；仍调用真实 Worker JWT 验签。Vite 代理忽略测试身份头，剥离浏览器 cookie 与 Access assertion，拒绝未知 Host、外站 Origin 与跨站浏览器请求。测试身份切换只在独立 E2E server 开启。此模块仅由开发配置和测试服务导入，不进入生产 Worker；它不证明真实 Cloudflare Access 登录成功，生产证据在 docs/17。

本地上游默认禁止外网媒体拉取；开发页面、上传、播放、分类、标签、收藏和设备协议均走本地状态。真实 X/Connector 的生产验收已单独完成，开发启动不读取私人书签或复制 X cookie。
