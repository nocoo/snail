# 15 · 品牌采用与来源

Snail 应用采用正式品牌 1.0.0；应用初版为 0.1.0，两者独立。品牌源是 Hexly v0.8.0，固定提交 `352eb2652d4e11c876ef84152fc8e02f8d5ed331`。[1]

## 采用证据

- 公开 manifest 与固定 Git blob SHA-256 均为 `11b8203d41030ad5317b94fd8a2a19d7a7b1077f174410b89caea4fd0d082ec8`，已实际下载比较。
- 从该 Git 提交读取 21 个所选原文件，校验大小与逐文件 SHA，再复制到 `public/brand/`；没有改 SVG、PNG、ICO、tokens、规范或许可的字节。
- `public/brand/upstream-manifest.json` 保存完整上游清单；`public/brand/provenance.json` 记录选用文件、来源提交、版本和哈希。完整清单列出的其余文件不宣称已复制到 Snail。
- 根目录 `logo.png` 与选定的 `logo-light.png` 字节相同；校验脚本还核对 ICO 的 16/32/48/64/128/256 像素目录。
- 采用提交：随本记录与实际消费者一同原子提交；确切 Git SHA 在发布记录中登记，不能预先伪造自身提交哈希。

## 消费位置

| 位置 | 资产与约束 |
|---|---|
| 桌面 Sidebar、手机 Sheet | 24px 透明 mark-light/dark；完整 viewBox，不裁剪、不铺底板；实际 Basalt `.dark` 状态决定版本 |
| 导航字标 | wordmark-light/dark，80px；页头字标 72px，无拉伸或淡化 |
| README | light/dark lockup 的 picture，227×96，完整 454×192 比例 |
| 浏览器 | 原始 favicon.svg 按系统主题；原始多尺寸 favicon.ico 兼容回退 |
| 安装图标 | icon-192.png、icon-light-512.png，manifest 的 purpose 为 any；原始 Apple touch 图标 |

导航的主题选择必须服从应用，而不能只依赖 OS；原始图案中的陶土点属于 Logo，不是健康灯。[2] UI 使用 Basalt 公共色彩 tokens 映射 Hexly paper/ink/surface/line；主要按钮采用 ink/paper 保持文字对比，陶土色保留为图案与焦点强调。品牌资产本身未被 CSS 滤镜、透明度或裁剪改色。

## 测试与后续更新

`bun run brand:check` 校验全部选用原字节、固定 manifest、根 logo 与 ICO；Biome 排除冻结品牌目录，防止格式化误改字节。Playwright 在 desktop/mobile、应用主题与系统主题相反的四种组合中验证实际可见文件、24px 无底板标记、至少 72px 字标、无 provisional 和实际 favicon；另检查导航说明不挤压 Logo。截图只在 `.artifacts/`。

不得覆盖上游 1.0.0 URL 或修改该版本原字节；几何、颜色和导出变更必须另立品牌版本。[2] 只写 Snail；通过已授权 Herdr 向 Hexly 维护者回传本仓库 adoption SHA 和实际产品 Release，不直接修改 Hexly。
