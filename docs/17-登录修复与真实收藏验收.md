一台最小权限 Connector 继续配对，凭据保存在 Keychain。验证用进程已停止，在仓库中运行以下命令即可继续接收网页批准的任务：

```sh
bun run connector -- watch
```

在资料库点击「收藏链接」，输入获准保存的 X 视频链接；「连接本机」查看设备和任务进度。`watch` 默认只处理逐条批准的任务；批量同步仍需显式 `--approve-rights`。支持范围和有界窗口约定见 [Connector 协议](13-Connector安装与协议.md)。
