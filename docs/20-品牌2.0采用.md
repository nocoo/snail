- 上游资料描述的是当时的 handoff 状态，其中 Snail 的待验证说明不是本仓库当前生产结论。真实登录和 Connector 验收以 [docs/17](17-登录修复与真实收藏验收.md) 为准。

旧 1.0.0 消费文件已从当前工作树移除，历史版本及其采用事实保留在 Git 和 [docs/15](15-品牌采用与来源.md)。本次只修改 Snail，没有修改 Hexly 的 `family.status` 或归档。

## 验证与许可

RED：桌面真实浏览器仍使用 `/brand/mark-light.svg`，与新 PNG 消费契约不符。GREEN：更新全部消费点后品牌定向测试通过，日志 `.artifacts/S19-brand-navigation-red.log` 与 `.artifacts/S19-brand-review-green.log`。

`bun run brand:check` 固定源 SHA、manifest 和全部 18 个目标字节，核对根 master、三种导航 PNG 与 ICO entry 的尺寸/RGBA。Chromium 独立解码四个透明源图与六个 ICO entry，全部具有透明、半透明和不透明像素，四角 alpha 为 0；证据 `.artifacts/S19-brand-decoded.json`。桌面/手机在应用与系统相反主题下检查品牌、尺寸、透明背景、无 mask/filter/shadow 和实际 favicon；另覆盖加载与过期会话登录卡。
