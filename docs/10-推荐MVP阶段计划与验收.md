# 10｜推荐 MVP、阶段计划与验收

**先验收认证与采集，再开发资料库体验。**当前总 Gate 为 CONDITIONAL GO；本机 OpenCLI 书签认证与示例文件搬运已经通过有限实验，仍不能保证跨日无人值守、全历史书签、文件夹同步或合法保存任意视频。[81][82]

本篇所有阶段、时间窗口、容量和验收阈值均为建议，不是平台承诺。本轮只交付文档和临时实验，没有排期承诺、产品代码或云端部署。

## 1. 推荐 MVP

主方案为 **Vite＋Cloudflare Worker＋D1＋私有 R2＋本机 OpenCLI Connector**。用户在自己的 Chrome 保持正常 X 登录；Connector 读取授权范围内的书签，Worker 负责限权接收、资料库元数据、媒体验证与保存。

| 范围 | MVP 建议 |
| --- | --- |
| 身份 | 单人资料库；Snail Access 登录与 X 会话独立；设备配对可撤销 |
| X 收集 | 先支持用户主动同步最近 120 条；重复读取去重，明确“历史未完成”；稳定性验收后再允许低频定时 |
| X 文件 | 只对获准媒体创建保存任务；从规范化 URL/字节入库；禁用原版 DOM download 自动发布 |
| 上传 | 用户有权保存的本地 MP4；有界 multipart、校验、恢复、封面 |
| 浏览整理 | 收件箱、网格、详情播放器、来源入口、文件夹、标签、星级、笔记、批量整理 |
| 搜索 | 条件筛选与中文包含匹配；不做语义向量、字幕识别或画面检索 |
| 文件服务 | 私有 R2、按资料库鉴权的 GET/HEAD/Range、摘要去重、取消和删除 |
| 明确延后 | X 文件夹映射、全历史保证、实时书签事件、云端 Chrome、团队、分享、剪辑、转码矩阵 |

安装版已实测限量分页可用，但文件夹 404；现有官方事件契约没有核实到 Bookmarks 新增/删除事件，这两项不能以界面占位假称完成。[81][65][66][68]

## 2. 阶段与退出标准

| 阶段 | 本阶段做什么 | 退出标准 / 失败后的决定 |
| --- | --- | --- |
| P0：本轮研究 | 只读 clone 审查；公共样本；本机 OpenCLI 认证/分页/下载验证；无秘密认证 contract | 已有 01–11 文档；保留失败证据，不提交身份、媒体或凭据。[56][81][82][83] |
| P1：认证及合规试点 | 只做受限 Connector、一次设备配对、版本固定、不注入 stealth；确认访问与保存依据 | 07 G1/G3/G5 通过；不能安全或合法复用会话就停止书签后台同步 |
| P2：一条端到端 | 对用户自有/许可视频：书签→规范化 metadata→真实 Worker/R2→鉴权播放 | 07 G2/G4；必须检查文件内容与哈希，而非 CLI exit 0 |
| P3：资料库 MVP | 上传、整理、搜索、删除；本机离线/失败状态；配额与基本审计 | 下方验收表通过；沿用 09 既有费用模型，不把低成本作为放宽 Gate 的理由 |
| P4：可选纯云端 | 官方 App、最小 OAuth scopes、实际 Bookmarks、刷新、撤销及账单 | G6 通过才移除对本机在线的依赖；未过则保留混合架构 |
| P5：按证据扩展 | 更深历史、文件夹、智能筛选、需要时的媒体工具 | 有真实需求、权限及样本，才增加 extractor/ffmpeg 或更复杂流程 |

P1/P2 只需验证关键链路，不应先搭完整 Eagle 式 UI。P3 才是产品开发阶段，不在本轮授权范围。

## 3. 可验收的闭环

### 已做与待做分开

| 检查 | 当前证据 | 下一步验收 |
| --- | --- | --- |
| 本机已登录账号读取书签 | GO：CLI 3 条；安装 adapter 的 1/120 limit、真实两页 200、ID 去重及示例命中。[81] | Chrome 重启、休眠、过期与账号切换；跨 7 天低频样本 |
| 本机文件夹 | 失败：404、30 字节、哈希已记录。[81] | 若为必须功能，先修复/选择合法可用接口再承诺；否则移出 MVP |
| 原版单帖 download | NO-GO：伪 MP4、非目标收集、blob 失败。[82] | wrapper 必须拒绝这些输出；不修改本轮上游 |
| 精确书签 MP4 | GO：200、505,479 字节、可解码、首尾 206、越界 416。[82] | 云端出口、媒体 URL 过期、不同获准样本与大文件 |
| 公开样本最高档 | GO：1,729,313 字节，视频/封面及本地 R2 摘要一致。[56] | 不扩大成任意 X 链接承诺 |
| Worker 数据流 | 本地 GO：直接 Response.body 及 FixedLengthStream 写模拟 R2；普通未知长度转换流失败。[56][82] | 真正 R2、断流、CPU/内存、限额、取消/清理 |
| OAuth/认证 contract | 17/17 本地 mock 通过。[83] | 不等于实际 X OAuth grant 或 Access JWT 验证 |
| 官方 X 用户上下文 | 尚未真实授权；匿名检查 401。[81] | 按 07 最小授权步骤与 G6 进行，不向聊天提交秘密 |

### 产品验收清单（待实施）

| 领域 | 通过标准 |
| --- | --- |
| 身份边界 | 未登录不能访问自己的库；不同用户/设备不能读写对方 item、job、part、媒体；Access 与设备凭据不能互相扩大权限 |
| 配对与撤销 | code 过期/重放失败；仅用户批准可兑换；设备 token 仅本机钥匙串持有、服务器只存摘要；撤销后旧上传和晚到任务不可发布 |
| X 会话隔离 | 请求 Snail 的录制测试中没有 X cookie、Authorization/CSRF 值、Chrome profile 或原始页面；无偷读其他 profile、无指纹补丁/验证码求解 |
| 来源准确性 | 所有导入媒体可对应被批准的 post/media；对 08 真实失败场景，不导入回复/推荐、不把页面当 MP4 |
| Bookmarks 完整性 | 界面区分最近窗口、部分分页和完整扫描；老帖新收藏可发现；重复 poll 不重复创建；未完扫描不推断取消收藏 |
| 官方 OAuth（可选） | PKCE S256、state/会话绑定、30 秒内交换、最小 scopes、真实 `/users/me` 绑定、refresh/invalid_grant/撤销验证，无秘密日志 |
| 文件完整性 | 接收字节、完整 SHA-256 与 R2 读回一致；声明 MIME、真实签名及可播性分开；伪装 HTML 被拒绝 |
| Range | 完整 GET/HEAD、首段、尾段、开放结尾、越界、非法/多范围、If-Range/ETag 均有定义；401/403 与 Range 组合不越权 |
| 上传恢复 | 8 MiB part 的重传不重复计费；中断后只补缺片；过期 session 不可复用；完成操作重放不重复增加引用 |
| 一致性 | 重复 Queue 消息、超时旧 lease、R2 完成/D1 失败、取消与完成竞争均不产生重复发布或永久孤儿 |
| 去重 | 同源链接换查询参数不新增来源；相同文件跨上传与 X 导入只计同库一份字节；不同清晰度不错误合并 |
| 整理与搜索 | 中文标题/笔记/标签包含匹配满足样本查询；文件夹无环；批量操作逐条鉴权；用户编辑不被同步覆盖 |
| 删除与合规 | 普通回收站、彻底删除、来源撤回区分；无引用对象清理；权利撤回禁止恢复；不将资料库默认为公开分享 |
| 离线与降级 | 电脑离线可解释、积压有上限；云端已有文件继续播放；无法登录不假报同步成功 |
| 用量 | 字节/任务额度先预留后结算；超额有明确信息；停止新导入不会妨碍读取/删除已有资料 |

涉及 OAuth 30 秒授权码窗口的依据见官方指南；表中其余具体策略与目标均为本研究设计。[59]

## 4. 失败与降级决策

| 失败 | 降级 |
| --- | --- |
| 本机离线 | 保留已存 R2 内容；书签任务等待，前端给最后同步时间 |
| X 会话失效 | 正常人工重登；不开云端 cookie 代理；若用户不接受反复登录，停止自动同步 |
| GraphQL/schema/query ID 失效 | 暂停 connector sync，保留诊断；不继续空数组成功；只发送当前页面的来源链接 |
| 文件夹不可用 | Snail 本地分类继续独立工作，X 文件夹同步不出现在可用能力中 |
| 原版下载产物不是视频 | 拒绝发布；只使用已批准的精确媒体 URL 或用户上传，不反复运行整页下载 |
| 媒体 URL 云端拒绝，但本机正常获准访问 | 本机下载后受限分片上传；仍检查权利，不扩大到保护/付费/DRM |
| 官方 OAuth 权限/套餐或刷新不可行 | B=NO-GO，保留 C；若 C 也不被接受则降级“上传＋单链接／扩展发送” |
| 法律依据不成立或权利未知 | 不复制视频；只提供合法上传/允许的来源链接，必要时关闭对应来源集成 |
| HLS/编解码不兼容 | 获准时转单个隔离本机工具；否则文件/链接降级，不在 Worker 引入未经验证的大型 WASM 转码 |

这不是自动绕过链。用户会话、官方 API、公开页面各有独立授权和能力边界，失败不能触发尝试更多身份或突破访问控制。

## 5. 风险登记

| 风险 | 本次依据 | 缓解 / 放行标准 |
| --- | --- | --- |
| 会话单次可用、长期失效 | 当前只在同日完成正常会话读取。[81] | 跨日/重启/休眠、账号切换试点；允许明确重登状态 |
| CLI 假成功与采集范围错误 | 真实 HTML→MP4、非目标 URL。[82] | 强校验、来源 ID 关联，禁止使用其 success 字段直接发布 |
| 通用浏览器桥权限过大 | 扩展权限、回环 daemon 与 cookie/evaluate 能力已读。[37][80] | 专用 profile、窄 wrapper/扩展、设备 scopes，禁止公网暴露 |
| 默认反检测路径冲突 | 安装版 goto 有 stealth；跳过后仍读成功。[80][81] | Connector 明确不调用该路径；无法正常访问则停止 |
| 官方契约与实际权限不一致 | 文档有 URL/OAuth 描述差异，真实 API grant 未做。[59][65][76][81] | 固定使用文档交集，实际授权/分页/刷新验证，不凭 README |
| 私人书签信息泄露 | 真实 Bookmarks 含正文/作者/媒体，范围比单条链接大。[81] | 最少字段、库隔离、日志白名单、临时原始响应删除 |
| 内容访问与版权混淆 | X 条款/政策限制抓取及内容使用。[12][13] | 逐功能访问依据、逐媒体权利、无默认再分发、可撤回 |
| Cloudflare 运行限制 | 128 MB、流长度要求、本地与云端出口差异。[16][56] | 流式、bounded multipart、真实云端测试、故障清理 |
| 依赖更新与许可证 | 上游版本/依赖/许可证不同，安装版不是 clone HEAD。[37][38][39][40][41][79] | 固定版本及 hash，升级回归，按实际分发物核验许可 |
| 书签“全量”误导 | limit 120 后仍有 next cursor，folders 未成功。[81] | 明确范围与 complete 标记，产品不承诺未证实历史能力 |

## 6. 开放问题（不阻塞本轮文档交付）

1. 用户是否接受本机在线才同步，以及需要同步最近多少条/多久一次；研究默认最近 120 条、低频可选，不将此假设写成已批准长期任务。
2. 是否愿意为 Snail 使用专用 Chrome profile，或更倾向以后安装窄权限扩展；不能假设当前通用桥已满足产品级隔离。
3. 文件夹是不是必须能力；当前 404 的原因需在未来合法接口调查中确定，而不是自动订阅/购买套餐。
4. 是否存在可明确验证版权与平台访问依据的测试视频集；给定示例技术成功不能代替这一点。
5. 未来是否要求电脑关机后继续同步；若是，官方 OAuth G6 必须先做，需确认 App 所有权与 Owned Reads 条件。
6. 全历史数量/删除对账的实际要求是什么；不能承诺只凭最近窗口解决完整归档。
7. Worker 云端的实际 CDN 访问、较大文件 CPU/内存及 R2 成本是否落在 09 的预算中；未测之前不扩建架构。

当前可以作出的决定是启动受限 Connector 认证试点，而非完整产品开发。用户若只要稳定上传和主动发送素材，降级产品也成立，但应明确去掉“自动同步我的 X 书签”的承诺。
