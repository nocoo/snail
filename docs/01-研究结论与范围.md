# 01｜研究结论与范围

研究日期：2026-09-12（Asia/Shanghai）。状态：文档及限定实验完成，产品认证验收仍有条件；未开发或部署产品。

## 1. 认证 Gate 先行

**认证 Gate：CONDITIONAL GO。本机 OpenCLI 已真实读取自己的 X Bookmarks、完成两页分页并命中给定示例，认证与有限书签读取为 GO；正式自动同步仍须通过生命周期、安全边界和真实云端端到端验收。**[81][82]

推荐 **Vite＋Worker＋D1＋私有 R2，以及一个本机 OpenCLI Connector**。Chrome 保管 X 登录态，Connector 发送规范化元数据与获准媒体 URL／字节；Worker 不接收 X cookie，负责校验、去重、存储和播放。不能以公开单链接成功替代私人 Bookmarks 认证，也不为认证未过关的路线继续扩写成本。

| 核心问题 | 真实证据 | 决策 |
| --- | --- | --- |
| 能否读取“我的书签” | OpenCLI 1.8.6 CLI limit 3 成功；同一安装 adapter 的无 stealth 观察器 limit 120 经两次 GraphQL 200 返回 120 条不重复书签；示例在其中。[81] | **本机认证 GO**；全历史、跨日稳定性未验收 |
| 现成单帖 download 是否可用 | exit 0，却把 3 个 HTML 页面保存成 MP4；还误收非目标媒体；本机没有其依赖的 yt-dlp。[82] | **原命令 NO-GO**，不能按成功字段直接入库 |
| 书签里的精确 MP4 是否能搬运 | OpenCLI 底层函数无 cookie 下载 505,479 字节 MP4；完整解码、Range 206/416 通过。[82] | **本例字节链路 GO**，保留格式与来源验证 |
| 文件夹是否可读 | 现有 bookmarkFoldersSlice 返回 404。[81] | 功能失败，原因未定；不承诺 X 文件夹同步 |
| 纯 Worker 是否足够 | 本机 workerd 真实 fetch CDN→R2 模拟绑定→读回哈希/Range 成功；无法直接运行用户 Chrome/OpenCLI。[82][22] | 采用最小混合架构；真实 Cloudflare 出口待测 |
| 未来纯云端 | 官方 OAuth 有 Bookmarks、PKCE、refresh/revoke；当前没有真实账号 grant/套餐验证。[59][60][61][65][81] | **CONDITIONAL GO**，另做官方授权，不上传 Web cookie |
| 视频保存权 | API scope、书签与公开 CDN 地址都不是离线复制/再分发许可。[10][12][13] | 有权保存才入 R2；未知权利保留允许的来源链接 |

G1–G5 是开发前门槛：无指纹补丁的跨日会话恢复、真实 Worker/R2 接力、设备撤销与过期、轮询增量/去重恢复、合法保存与删除；全部列于 [07](07-X登录与认证可行性.md)。如果本机在线不能接受且官方 OAuth 实验不通过，产品明确降级为 **“上传＋单链接导入／浏览器扩展发送”**，不承诺后台同步我的书签。

## 2. 公开单链接实测摘要（辅助证据）

输入：`https://x.com/girlofflorence/status/2098577796398567727?s=46`。

- 页面和 oEmbed 能取得帖子、作者、正文及来源信息；页面另外包含媒体 ID、缩略图、时长和变体，oEmbed 返回的是嵌入信息，不能单独承担视频文件解析。[1][2][8][56]
- 最高 MP4 档为 **720×1280，1,729,313 字节**；SHA-256 为 `2ee43bb5411bbae7baaa856bbb36debc01fe97d7f2b4cd288d72684d4994ea1e`。[5][56]
- X 页面声明时长 **7.082 秒**，ffprobe 读到容器时长 **7.128526 秒**；视频为 H.264，音频为 AAC，不能把两个时长混为一项。[1][56]
- 缩略图返回 `image/webp`，**169,456 字节**，已经完成下载与 R2 模拟绑定读回哈希核对。[7][56]
- 未带凭据的官方 API 返回 **401**；未加客户端参数的公开 syndication 请求返回 **200 和 `{}`**，不能将 HTTP 200 等同于成功取得媒体。[3][4][56]
- `ReadableStream → R2.put()` 直接传递成功；普通 `TransformStream` 后写入因长度未知失败；加入 `FixedLengthStream` 后，边计数、边计算 SHA-256、边写入成功。[56]

完整请求、响应大小、哈希、范围值与复现方法见 [02](02-X示例实测与最小Spike.md)。

## 3. 产品目标

以下是设计目标，不是当前已实现功能。

1. 为个人保存有权使用的视频素材，形成“收集 → 快速浏览 → 分类 → 再找到”的闭环。
2. 在授权本机在线时读取自己的 X Bookmarks，与上传和单链接归入同一个资料库；明确区分“只保存了链接”和“文件已保存”。
3. 网格缩略图、悬停静音预览、详情播放器、文件夹、标签、星级和笔记形成类似 Eagle 的组织体验。
4. 视频及缩略图存 R2，业务元数据存 D1，前端用 Vite 构建。
5. 导入进度可恢复、失败原因可解释，重复导入不产生重复文件。
6. 将版权、平台许可、账号隔离、SSRF 和费用上限作为导入流程的约束。

Eagle 官方产品页列出了浏览器收集、文件夹、标签、智能文件夹、重复文件处理、悬停预览及视频书签，这些是体验对标的依据。[14]

## 4. 非目标

- 本轮不创建 Vite 工程、数据库迁移、Worker 服务、R2 桶、登录系统或远端仓库。
- MVP 不做视频剪辑、多码率转码、直播录制、自动字幕、语义向量搜索或团队协作。
- 不复制 Eagle 的桌面文件格式、插件生态和完整素材格式支持。
- 不同步整条 X 时间线、整个人的媒体库或私信；自己的私密 Bookmarks 列表已纳入认证研究，其他人的私人书签及受保护帖子视频不在范围。
- 不解密 DRM、不处理付费或受保护内容，不求解 challenge、不轮换代理或账号规避限制。
- 不宣称文件永久可取得，不将下载器“支持 Twitter”当作成功率承诺。
- 不发布、共享或提交本例视频、缩略图、cookie、token、原始网页状态或会话文件。

## 5. 关键决策

| 决策 | 当前选择 | 触发重新评估的条件 |
| --- | --- | --- |
| 前端 | Vite 静态应用；浏览器原生 video 播放器；不为研究搭建 UI | 开始产品阶段 |
| 服务端 | Worker 负责鉴权、URL 规范化、任务、下载流和播放 Range | 云端出口或负载实测不通过 |
| 长任务 | Queue 消费任务，D1 保存状态和领取租约 | 多步骤恢复复杂到单任务无法管理时才考虑 Workflows |
| 二进制 | 私有 R2，随机不可变对象 key，成功校验后发布数据库引用 | 存储量、归档策略发生变化 |
| 上传 | 浏览器按 8 MiB 分片，经 Worker 有界流式写 R2 multipart | Worker 中转成为已测得的瓶颈时再考虑预签名直传 |
| X 元数据 | 优先本机已验证的 OpenCLI Bookmarks；oEmbed 只做单链接卡片 | 官方 OAuth 真实授权通过，或本机使用条件变化 |
| X 视频 | 精确定位获准 MP4，禁用原版整页 download 入库；记录选中清晰度 | 合法来源只提供 HLS 或格式不兼容 |
| 混合运行 | 一个本机 Connector 为主要认证入口；无需常驻云浏览器 | 需要 ffprobe/ffmpeg，或官方 OAuth 纯云端通过 |
| 搜索 | D1 条件筛选；中文包含匹配先行；FTS5 留给英文分词检索 | 真实资料规模和中文查询集证明需要升级 |

Vite 可输出静态构建产物；R2 绑定支持流式对象读写；D1 提供 FTS5；Queues 是至少一次投递，因此去重及幂等不能省略。[15][17][28][30]

## 6. 研究边界与证据纪律

前半段对给定单帖及公开媒体做无登录请求；在用户明确授权后，通过 OpenCLI 正常复用本机登录会话只读书签，并只对给定示例做后续精确视频下载。没有 X 写操作、真实账号登出、验证码求解或 HLS 密钥下载。本例 MP4 已能直接读出音视频轨道，所检查的 HLS 清单未出现加密 key 标签；该观察仅适用于本次返回，不能推广到其他视频。[56][82]

原版 OpenCLI 的默认导航会注入指纹补丁，发现后已在后续观察器中跳过，书签读取仍通过；详情见 08，不能把原 CLI 的默认实现宣称为已经满足全部产品安全要求。[80][81] “已获完整法律授权”没有证据。X 现行条款和开发者政策对自动访问、离线保存、内容变更及再分发有要求，正式启用自动复制前仍须确认适用许可。[12][13]

上游在 `~/workspace/references/snail-research-20260912-*` 独立 clone，完成源码及许可证只读审查；没有修改上游工作树。临时实验位于 `/tmp/snail-research-iKKC3rYb/`，研究结束时清除媒体副本、私人原始响应和 R2 模拟对象；仓库交付仅包含本组文档，清理状态见 Sources。[56][81][82]
